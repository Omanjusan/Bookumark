# 改修予定機能

## ブックマーク配置種類の一覧改修

ブックマークの一覧表示を、縦幅を抑えた高密度な横並びの構成へ改修する。名前、登録日、閲覧回数、最終訪問日などのソート項目に対応する見出しを設け、各要素を左寄せで表示する。

## パネルモードの背景色フレーバー

ブックマークがスケーリング表示されるパネルモードだけを対象に、ランダムな背景色を使った賑やかし要素を追加する。ほかの表示形式や上下ベイなどには適用しない。

## 仮想グループによるタブ管理POC

開いているタブを一覧化し、ユーザーが作成したグループへD&Dでタブを追加して、Bookumark内で仮想的にグループ管理できるか検証する。仮想グループから実際のタブを呼び出せるようにし、対象タブがブラウザー側ですでに閉じられている場合は、その状態を一覧と仮想グループへ反映する。
