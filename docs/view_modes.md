# 表示形式・切替UI設計

策定日: 2026-07-25

## 1. 目的

検索、フィルタ、ソート後の同じ表示集合を、用途の異なる複数の表示形式で切り替えて閲覧できるようにする。

本書では初期版の表示形式、共有状態、切替UI、各形式の情報量、ブックマーク操作との共通契約および実装フェーズを定義する。

## 2. 初期版の表示形式

初期版は次の4形式とする。

| ID | 表示名 | 役割 | スケール |
| --- | --- | --- | --- |
| `panel` | パネル | 訪問順位をタイル面積へ反映する | 対応 |
| `icon` | アイコン | 均一サイズで視覚的に一覧する | 非対応 |
| `card` | カード | 利用実績をテキストで常時確認する | 非対応 |
| `list` | 一覧 | タイトルとドメインを高密度に表示する | 非対応 |

旧案にある5つ目の「詳細」は初期版へ含めない。カードと役割が重なり、詳細表示に必要なメモとユーザー属性も未実装であるため、それらの機能が揃った段階で改めて設計する。

## 3. 共通状態

表示形式はチップインスタンスごとに選択値の正本を持たず、共通アプリ状態を参照・更新する。

```ts
type ViewType = "panel" | "icon" | "card" | "list";

type FixedDisplayState = {
  query: string;
  filters: readonly DisplayFilter[];
  display: DisplayState;
  activeViewType: ViewType;
};
```

- 初期値は`panel`とする。
- 表示形式を変更しても検索、フィルタ、ソート、移動モードを維持する。
- パネル再読み込み時は`panel`へ戻す。
- 初期版では選択状態を永続化しない。
- 永続化はDB-4以降の保存モデルで扱う。
- 同じ表示形式チップを複数配置した場合、すべてが同じ`activeViewType`を表示する。
- チップの初期化だけで表示形式を変更せず、ユーザー操作時だけ更新する。

## 4. 切替UI

表示形式ベイを下レールのソートベイと移動モードベイの間へ固定配置する。

```text
[ パネル ] [ アイコン ] [ カード ] [ 一覧 ]
```

- HTMLのradio groupをCSSでセグメント表示する。
- 同時に選択できる状態は必ず1つとする。
- 矢印キーで選択状態を変更できるようにする。
- スクリーンリーダーへ「表示形式」の4択として伝える。
- 変更時は即時再描画する。
- 表示名は短縮せず「パネル」「アイコン」「カード」「一覧」を使用する。
- 狭幅ではベイ単位で折り返し、セグメント内部は分断しない。

## 5. 表示集合の共通契約

すべての形式は、共通コントローラーが生成した検索、フィルタ、ソート後の表示集合を入力とする。

```text
Firefoxブックマークと履歴
  → 現在フォルダ直下
  → 検索
  → フィルタ
  → ソート
  → 選択中の表示形式で描画
```

- 表示形式ごとに検索、フィルタ、ソートを再実装しない。
- 表示形式を変えても項目の順序を変えない。
- フォルダは既存の固定フォルダ領域に表示し、表示形式切替の対象外とする。
- 読み込み中、0件、エラーの状態表示は全形式で共通とする。
- 描画処理は入力項目と共有状態を変更しない。

## 6. 各形式の情報量

### 6.1 パネル

- 既存の7段階スケール表示を使用する。
- スケーラブルなソート軸では順位を面積へ反映する。
- 非スケーラブルな軸とカスタム配置では全項目を等倍にする。
- サイズ別の情報量は`mode_panel.md`に従う。

### 6.2 アイコン

- 全項目を均一サイズで表示する。
- 52pxのアイコンと最大2行のタイトルを表示する。
- グリッドは`repeat(auto-fill, minmax(86px, 1fr))`を基準とする。
- 行間と列間はそれぞれ20px、10pxを基準とする。
- 訪問回数と最終訪問日時は常時表示しない。
- ホバー時は淡い背景で対象を示す。

### 6.3 カード

- 全項目を均一サイズで表示する。
- 48pxのアイコン、タイトル、ドメイン、訪問回数、最終訪問日時を表示する。
- グリッドは`repeat(auto-fill, minmax(270px, 1fr))`を基準とする。
- カードの最小高さは96pxを基準とする。
- 訪問回数の欠損は「履歴不明」、0回は「未訪問」として区別する。
- 最終訪問日時の欠損は「記録なし」と表示する。
- 将来のメモ表示領域は予約するが、メモ機能が存在しない間は描画しない。

### 6.4 一覧

- 全項目を24px基準の1行5列テーブルとして表示する。
- 列は16pxのアイコン、タイトル、登録日時、最終訪問日時、訪問回数の順とする。
- アイコン列の見出しは表示せず、残る4列の見出しを表示する。
- 4列の見出しはボタンとし、別の列を選ぶと昇順、選択中の列を再度押すと昇順・降順を反転する。
- 現在のソート列と方向を`▲`または`▼`で示し、既存の共通ソート状態およびソートチップと同期する。
- 全セルを左揃えとし、タイトルへ残り幅を割り当てる。
- 一覧全体と通常行は透明背景とし、hover行だけを淡い背景で示す。
- 狭幅でも列を省略せず、テーブルの横スクロールで全列へアクセス可能にする。
- 5列それぞれの幅を独立した設定として保持し、アイコン、タイトル、登録日時、最終訪問日時、訪問回数の初期幅を順に24px、292px、160px、160px、84pxとする。
- 各列の最小幅は順に24px、60px、64px、64px、36pxとし、保存値が最小幅を下回る場合は最小幅へ補正する。
- 列幅は一覧表示全体で共有する専用設定として永続化する。列境界の操作は対象境界の左側1列だけへ作用し、テーブル全幅の増減は横スクロールで扱う。
- 取得できない日時と訪問回数は`—`、取得済みの未訪問回数は`0`と表示する。
- 一覧右上の歯車から日付表示設定を開き、ブラウザー、ISO、日本、米国、英国、欧州の方式を選択できる。
- 日付方式は選択時に即時反映して拡張機能全体の設定として永続化し、初期値はブラウザー方式とする。
- 設定オーバーレイは外側操作では閉じず、明示的な`×`操作まで表示を維持する。

## 7. 共通操作契約

- 左クリックは既存どおり新しいアクティブタブでブックマークを開く。
- カスタム配置では現在フォルダ内の表示順だけを変更する。
- 公式整理ではFirefox公式順と公式フォルダ階層を変更する。
- 通常モードではD&Dを無効にする。
- 検索またはフィルタ中は全形式でD&Dを無効にする。
- `data-guid`と`data-url`を持つ共通の操作対象契約を使用する。
- 形式固有の子要素をクリックしても、最も近い操作対象を解決する。
- 先頭、末尾、項目間のdrop契約を形式間で統一する。
- 表示形式切替中にブックマークを開く操作やD&Dを発火させない。

## 8. 状態遷移

| 操作 | `activeViewType` | 検索・フィルタ・ソート | 移動モード |
| --- | --- | --- | --- |
| 表示形式を選択 | 選択値へ変更 | 維持 | 維持 |
| 検索語を変更 | 維持 | 検索語だけ変更 | 必要時`normal` |
| フィルタを変更 | 維持 | フィルタだけ変更 | 必要時`normal` |
| ソートを変更 | 維持 | ソートだけ変更 | 既存契約に従う |
| パネルを再読み込み | `panel` | 初期状態 | `normal` |

## 9. TDD実装フェーズ

各フェーズを独立したGO、Red、Green、必要時のRefactor、テスト結果報告、STAYの単位とする。

| フェーズ | 内容 | 主な完了条件 | コスト |
| --- | --- | --- | ---: |
| DB-3D-1 | 表示形式状態と切替UI | 4択と`activeViewType`が双方向に同期する | 中 |
| DB-3D-2 | 一覧式 | 現行データ・操作契約で高密度な1行表示が動く | 中 |
| DB-3D-3 | アイコン式 | 均一グリッドと共通操作が動く | 中 |
| DB-3D-4 | カード式 | 利用実績と欠損状態を区別して描画できる | 中〜大 |
| DB-3D-5 | 4形式の連携回帰 | 検索・フィルタ・ソート・D&Dが全形式で一貫する | 大 |

## 10. テスト観点

- 初期表示がパネル式になる。
- 4択が排他的に遷移する。
- 複数の切替UIが同じ選択状態を表示する。
- 初期化だけでは表示形式が変化しない。
- 切替前後で検索、フィルタ、ソート、移動モードを維持する。
- 4形式が同じ入力順を維持する。
- 表示形式に関係なく空状態とエラー状態を表示できる。
- 訪問回数0、欠損、最終訪問日時欠損を定義どおり表示する。
- 各形式でクリック、カスタム配置、公式整理が同じ項目を対象にする。
- 検索・フィルタ中は各形式でD&Dが無効になる。
- 入力データと共有状態を変更しない。

## 11. 保留事項

- 5つ目の詳細形式
- 表示形式の永続化
- メモとユーザー属性のカード・詳細表示
- 中クリック、修飾キー、キーボードだけの項目操作
- アイコン式とカード式の寸法はFirefox実機で最終調整する。
