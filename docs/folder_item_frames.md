# フォルダ欄・アイテム欄の上下分離仕様

策定日: 2026-08-03

## 1. 目的

現在フォルダ直下のフォルダとURLアイテムを、役割の異なる上下2領域として表示する。フォルダは上側のナビゲーション領域、URLアイテムは下側の4表示モード領域とし、ユーザーが現在のシーン内で表示配分を調整できるようにする。

★お気に入り表示、フォルダ新規作成、URLアイテム新規作成は本仕様の対象外とする。ただし、両方の新規作成導線を後から追加できる構造上の余地は残す。

## 2. 表示構造

```text
┌──────────────────────────────────────[⚙]─┐
│ フォルダ                              ↕ scroll│
└───────────────────────────────────────────┘
 [フォルダ欄を1段階広げる] [アイテム欄を1段階広げる]
┌───────────────────────────────────────────┐
│ URLアイテム                          ↕ scroll│
└───────────────────────────────────────────┘
```

- フォルダ欄を上、URLアイテム欄を下へ配置する。
- 各欄は個別の背景と1本の外枠を持ち、別領域であることを示す。
- 2つの外枠の間には数pxの視覚的な空白を設ける。
- 横見出し行および左側の縦操作帯は設けない。
- フォルダ欄は4表示モードの切替対象外とする。
- URLアイテム欄だけがパネル、アイコン、カード、一覧の表示モードに従う。
- 各欄の内容は独立して縦スクロールする。操作部と歯車は内容と一緒にスクロールさせない。
- 通常時はページ全体をスクロールさせない。極端に低い画面では、両欄の最低高さとベイの操作可能性を守ったうえで、2欄を含む中央領域全体の縦スクロールを許可する。

## 3. 空状態と最低高さ

- 両欄は0件でも非表示にしない。
- フォルダ欄は最低1行分の自然な空欄を残し、説明、破線、未実装ボタンを表示しない。
- URLアイテム欄は最低1行分の高さを残し、既存の空状態を表示する。
- どちらの欄も完全には折り畳まない。
- 将来の新規作成機能は、この空欄または枠内の専用導線として追加できるものとする。

## 4. 段数状態

フォルダ欄の高さは、既定段数、シーン内希望段数、実効段数を分離して扱う。

```text
基準段数 = シーン内希望段数が存在すればその値、なければ既定段数

実効段数 = min(
  基準段数,
  現在のフォルダをすべて表示するために必要な段数,
  利用可能な画面高の25%以内に収まる段数
)
```

- 未設定時の既定段数は3段とする。
- 既定段数とシーン内希望段数は1～5の整数とする。
- 実効段数は最低1段とする。フォルダが0件の場合も1段分を確保する。
- フォルダが希望段数より少ない段数に収まる場合は、実効段数だけを自動的に縮める。
- 25%上限で希望段数を表示できない場合も、実効段数だけを一時補正する。
- 自動縮小、ウィンドウ寸法変更、25%補正によって既定段数またはシーン内希望段数を失わない。
- フォルダ欄が実効段数分を必要としない場合、残りの高さはURLアイテム欄へ割り当てる。

## 5. 枠間の段階操作

枠間へ次の2つの文字ボタンを横並びで配置する。

- `フォルダ欄を1段階広げる`
- `アイテム欄を1段階広げる`

動作は次のとおりとする。

- フォルダ欄を広げる操作は、現在の基準段数を1増やした値をシーン内希望段数とする。
- アイテム欄を広げる操作は、現在の基準段数を1減らした値をシーン内希望段数とする。
- 一方を広げた分だけ他方へ割り当てる高さを減らし、2欄の合計利用高は変えない。
- 現在のフォルダ数と画面寸法から両方向の操作後の実効段数を事前計算する。
- 片方向でも実効段数が変わらない場合は両ボタンを無効化し、シーン内希望段数を変更しない。
- フォルダ数または画面寸法が変わるたびに操作可否を再計算し、両方向とも実効段数を変えられる状態になれば両ボタンを再び有効化する。
- 高さ変更前後で、両欄それぞれのスクロール位置を維持する。

## 6. 既定段数設定

- フォルダ欄右上へ、見出し行を占有しない歯車ボタンを配置する。
- 歯車とフォルダ項目が重ならないよう、内容側に必要な余白を確保する。
- 歯車からモーダルを開き、既定段数をスピンボックスで設定する。
- 設定可能な値は1～5の整数だけとし、0、負数、小数、空欄、6以上および非数値を正式値として受け付けない。
- 未保存または破損した保存値は3へ補正する。
- 確定ボタンは配置しない。
- スピンボックス操作中は下書きとし、`×`を押したときに保存する。
- 保存成功後にモーダルを閉じ、新しい既定段数を現在のシーンにも適用する。
- 保存失敗時はモーダルを閉じず、個人情報や内部情報を含まない固定エラーをモーダル内へ表示する。
- モーダル外の操作では閉じない。
- `Escape`は下書きを破棄して閉じる。
- 再度開いたときは、最後に保存成功した既定段数を表示する。

## 7. シーン境界

次の操作をシーン変更とし、シーン内希望段数を破棄して既定段数を再採用する。

- フォルダへの移動
- フォルダ履歴の戻る、進む
- パネル、アイコン、カード、一覧の表示モード切替
- パネルの再読み込みおよびFirefox再起動
- レイアウト再構築

次の操作はシーン変更とせず、既定段数およびシーン内希望段数を維持する。

- 検索
- フィルター
- ソート
- ウィンドウ寸法変更
- 各欄のスクロール
- 将来のお気に入り関連操作

スクロール位置は永続化しない。フォルダ移動、フォルダ履歴移動、パネル再読み込み、Firefox再起動では両欄を先頭へ戻し、表示モード切替ではURLアイテム欄を先頭へ戻す。

## 8. 永続化

- 永続化する表示配分設定は既定段数だけとする。
- シーン内希望段数、実効段数、スクロール位置は永続化しない。
- 保存設定はBookumark全体で共有し、フォルダ別または表示モード別に分けない。
- 読み込み・補正保存に失敗した場合は、既存の安全な起動および固定エラー通知の契約に従い、不完全な設定を正式状態へ昇格させない。
